STEP 3 — DEPLOY THE CONTACT EMAIL EDGE FUNCTION
The static GitHub Pages site cannot send email securely by itself. Deploy the included function at:
  supabase/functions/send-contact-email/index.ts
as an Edge Function named exactly: send-contact-email
In Supabase Dashboard → Edge Functions, create/deploy the function with the included code. Make sure JWT verification is disabled for this public contact form endpoint (the function validates fields, includes a honeypot and rate limit, and stores submissions server-side). The included supabase/config.toml contains the CLI setting if you deploy using the Supabase CLI.
